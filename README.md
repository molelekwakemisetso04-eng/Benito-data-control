# Kemisetso Executive Dashboard

Executive dashboard for automated CSV data cleaning, client task processing, and revenue management built with Flask & Pandas.

**Features**
- Secure executive authentication portal (`molelekwakemisetso04@gmail.com`)
- Automated CSV data cleaning pipeline
- Live revenue valuation and task counters
- Direct telephone dialing actions for client management
- Payment status tracker

**Deployment Architecture**
- Backend: Python, Flask, Pandas
- Production Server: Gunicorn
- Host: Render (Cloud Web Service)
